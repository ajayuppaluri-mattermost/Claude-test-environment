Sheets to PDF Converter

Convert each sheet in a Google Spreadsheet to a separate PDF

1 Setup (one-time)

You need a Google Cloud OAuth Client ID. Follow these steps once:

  1. Go to Google Cloud Console and create a project (or select an existing one)
  2. Enable the Google Sheets API and Google Drive API
  3. Go to OAuth Consent Screen — choose External, fill in the app name, and add your email as a test user
  4. Go to Credentials → Create Credentials → OAuth Client ID
  5. Application type: Web application
  6. Under Authorized JavaScript origins, add:
  7. Copy the Client ID and paste it below

Looks like: 123456789-abcdef.apps.googleusercontent.com

2 Sign in with Google

Sign in to grant read access to your spreadsheet and write access to upload PDFs.

Leave empty to only download PDFs locally
