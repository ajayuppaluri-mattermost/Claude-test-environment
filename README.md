# Claude Cowork Training Course

A hands-on, 3-day training course for non-technical users learning to use Claude Cowork.

**Live site:** https://ajayuppaluri-mattermost.github.io/Clade-cowork-training/

## Overview

This course teaches non-technical users how to get started with Claude Cowork through practical, guided exercises. It covers everything from initial setup to building daily workflows with connectors, scheduled tasks, and plugins.

## Course Structure

| Day | Topic | Duration |
|-----|-------|----------|
| **Day 1** | Getting Started & First Tasks — setup, first Cowork task, writing effective prompts, creating documents | ~60–75 min |
| **Day 2** | Real-World Work — analyzing files, creating presentations, multi-step projects, mid-task steering | ~60–90 min |
| **Day 3** | Power Features — global instructions, connectors, scheduled tasks, plugins, daily workflows | ~60–90 min |
| **Reference** | Quick reference card — essentials, prompt formula, troubleshooting, safety reminders | — |

## Prerequisites

- A paid Claude subscription (Pro, Max, Team, or Enterprise)
- Claude Desktop app installed
- An internet connection

## Running Locally

Open `index.html` in any web browser — no build step or server required.
